Puts a WordPress site into maintenance or coming soon mode with role-based access, IP whitelist, and passphrase bypass.

== Description ==

A lightweight plugin to put your site into maintenance or coming soon mode. Key features:

* Enable/disable toggle
* Maintenance mode (HTTP 503) or Coming Soon mode (HTTP 200)
* Custom display message via rich text editor
* Role-based access — choose which roles can bypass the page (admins always allowed)
* IP whitelist with one-click "Add My IP" button
* Bypass passphrase — visitors who know the passphrase get through
* Optional REST API and feed blocking
* WP-login and wp-admin are never blocked
